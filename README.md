# Scratch/Turbowarp Tutorials

This is a set of tutorials for teaching some basic concepts of programming in scratch and turbowarp. 
These project files were created in turbowarp, but most should work in scratch just fine (and maybe penguinmod if you change the extension).

## Folders in this repo:

**Scratch Tutorials:** These are the main tutorial files.

**assets:** different sprites I grabbed when creating some of the tutorials

**Finished:** kept for nostalgia, not useful for anyone else

**Special Versions:** These are specially created versions of the scratch tutorials. Some may work in TW, some may not. They are here for me.

**trystan-scratch:** I've decided to start storing some of my silly projects here. Not educational, but I wanted to keep them around.

**extensions:** Extensions that I've found interesting and have been playing with
